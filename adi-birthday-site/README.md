# Happy Birthday Adi 🎂

A multi-page birthday website with cat memes, confetti, mystery gift boxes and party mode.

## Deploy with GitHub Pages
1. Create a new repository on GitHub (for example `adi-birthday`).
2. Upload `index.html` and `README.md` to the repository root.
3. Go to **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select the `main` branch and the `/ (root)` folder, then click **Save**.
5. After a minute, your site will be live at `https://YOUR-USERNAME.github.io/adi-birthday/`.

Everything (including the images) is inside `index.html`, so no other files are needed.
